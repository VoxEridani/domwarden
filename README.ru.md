# Domwarden

**Domwarden следит за вашими доменами и предупреждает до того, как что-то сломается.**

Одна небольшая программа проверяет у каждого домена из списка:

- **SSL-сертификат** — это то, что даёт замочек в браузере. Сколько дней осталось до конца срока, доверяют ли ему браузеры, подходит ли он к адресу сайта, отдаёт ли сервер всю цепочку сертификатов;
- **оплату домена** — когда продлевать и не приостановлен ли домен (через RDAP, а для `.ru`, `.рф`, `.su` и других зон без RDAP — через WHOIS);
- **DNS** — есть ли у домена DNS-серверы и IP-адрес;
- **почтовые записи** MX, SPF, DKIM и DMARC — они доказывают Gmail, Яндексу и Mail.ru, что письма от вашего домена настоящие. Без них письма попадают в спам, а мошенники могут слать письма от вашего имени;
- **сайт** — открывается ли, как быстро отвечает, куда перенаправляет, переходит ли `http://` на `https://`.

О проблемах программа сообщает в **Telegram**, на **почту** или через **вебхук** (Slack, Discord или ваша система).

```text
> domwarden check example.ru

example.ru  ⚠ есть предупреждения
  ✔ DNS    DNS-серверы: ns1.reg.ru, ns2.reg.ru · example.ru → 194.58.112.174
  ⚠ Домен  оплачен до 2026-11-25 (осталось 23 дня) · регистратор REGRU-RU
           ⚠ регистрация заканчивается через 23 дня — не забудьте продлить
  ✔ TLS    действует до 2027-01-05 (осталось 64 дня) · выдан Let's Encrypt (R11) · TLS 1.3
  ✔ HTTP   200 OK · 312 мс · http:// → https://
  ✔ MX     mx.yandex.net (10) · Yandex 360
  ✔ SPF    v=spf1 redirect=_spf.yandex.net · 7 из 10 DNS-запросов
  ✔ DMARC  p=reject · отчёты на dmarc@example.ru
  ✔ DKIM   ключи: mail (RSA 2048)

Проверено: 1 домен за 1.9 с. В порядке: 0, с предупреждениями: 1, критично: 0
```

**Что означают значки:**

| Значок | Значение |
|---|---|
| ✔ | всё в порядке |
| ℹ | совет; проблемой не считается |
| ? | проверить не удалось (например, сервер реестра не ответил) |
| ⚠ | предупреждение: скоро понадобится ваше внимание |
| ✘ | критично: сломано сейчас или вот-вот сломается |

## Установка на Windows

1. Откройте страницу [Releases](https://github.com/VoxEridani/domwarden/releases) и скачайте файл
   `domwarden-...-x86_64-pc-windows-msvc.zip`.
2. Распакуйте архив в удобную папку, например `C:\Tools\domwarden`.
3. Откройте эту папку в Проводнике, нажмите правой кнопкой мыши на пустом месте и выберите
   **«Открыть в терминале»**. Откроется окно, куда пишут команды.
4. Введите команду и нажмите Enter:

   ```powershell
   .\domwarden.exe check example.com
   ```

   Вместо `example.com` подставьте свой домен. Можно перечислить несколько через пробел.

> В PowerShell перед именем программы из текущей папки нужно писать `.\`. Дальше в инструкции
> команды записаны коротко — `domwarden ...`; в PowerShell пишите `.\domwarden.exe ...`.

**Linux и macOS:** скачайте архив для своей системы, распакуйте и запускайте `./domwarden`.
Тем, у кого установлен Rust, подойдёт команда `cargo install --git https://github.com/VoxEridani/domwarden`.

## Файл настроек: список доменов

Чтобы не перечислять домены каждый раз, запишите их в файл настроек.

1. Создайте файл с подсказками:

   ```powershell
   .\domwarden.exe init
   ```

   Программа напишет, где создан файл. Обычно это `C:\Users\<имя>\AppData\Roaming\domwarden\domwarden.toml`.
2. Откройте его в Блокноте:

   ```powershell
   notepad "$env:APPDATA\domwarden\domwarden.toml"
   ```

3. Впишите свои домены вместо `example.com`. Каждый домен — в кавычках, после него запятая:

   ```toml
   domains = [
       "example.ru",
       "example.com",
       "пример.рф",
   ]
   ```

4. Сохраните файл и запустите проверку всех доменов сразу:

   ```powershell
   .\domwarden.exe check
   ```

Строки, которые начинаются с `#`, — это комментарии: программа их не читает. Чтобы включить
настройку, удалите `#` в начале строки. Если вы ошибётесь в названии настройки, программа покажет
номер строки с ошибкой.

**Настройки для отдельного домена** записываются блоком `[[domain]]`:

```toml
[[domain]]
name = "shop.example.ru"
hosts = ["shop.example.ru", "www.shop.example.ru"]  # какие адреса сайта проверять
skip = ["mail"]                                     # какие проверки пропустить: dns, domain, tls, http, mail
dkim_selectors = ["mail"]                           # селектор DKIM вашей почты (см. ниже)
```

**Сроки предупреждений** — в блоке `[settings]`:

```toml
[settings]
cert_warning_days = 14      # за сколько дней до конца срока сертификата предупреждать
cert_critical_days = 7      # ...и бить тревогу
domain_warning_days = 30    # то же для оплаты домена
domain_critical_days = 7
```

## Оповещения

Программа присылает оповещения, когда проверяет домены из файла настроек (так она работает по
расписанию). Если вы проверяете домены, указанные прямо в команде, оповещений не будет — добавьте
`--notify`, если они нужны.

После настройки отправьте пробное сообщение:

```powershell
.\domwarden.exe notify-test
```

### Telegram

1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather), отправьте ему `/newbot` и ответьте
   на вопросы (имя бота, адрес бота). В конце он пришлёт **токен** — строку вида `123456789:AAE...`.
   Никому её не показывайте: с ней можно управлять ботом.
2. Найдите своего нового бота по адресу и нажмите **«Запустить»** (Start). Бот не может написать
   первым, пока вы этого не сделали.
3. Узнайте свой **chat_id**. Напишите боту любое сообщение, затем откройте в браузере адрес
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (вместо `<ТОКЕН>` вставьте токен). Найдите на
   странице `"chat":{"id":123456789` — это число и есть chat_id.
   Для группы: добавьте бота в группу, напишите в ней сообщение и снова откройте ту же страницу.
   Номер группы начинается с минуса.
4. Добавьте в файл настроек:

   ```toml
   [notify.telegram]
   bot_token = "123456789:AAE..."
   chat_id = "123456789"
   ```

### Почта

```toml
[notify.email]
host = "smtp.yandex.ru"
port = 465
username = "you@yandex.ru"
password = "пароль приложения"
from = "you@yandex.ru"
to = ["you@yandex.ru"]
```

Важно: Яндекс, Mail.ru и Gmail **не принимают обычный пароль** от почты. Нужен **пароль приложения** —
отдельный пароль, который создаётся в настройках безопасности почты:

| Почта | Сервер (`host`) | Где взять пароль приложения |
|---|---|---|
| Яндекс | `smtp.yandex.ru` | Яндекс ID → Безопасность → Пароли приложений → Почта |
| Mail.ru | `smtp.mail.ru` | Настройки → Безопасность → Пароли для внешних приложений |
| Gmail | `smtp.gmail.com` | Аккаунт Google → Безопасность → Пароли приложений (нужна двухэтапная аутентификация) |

Порт 465 подходит для всех трёх.

**Пароль не обязательно хранить в файле.** Можно написать `password = "${DOMWARDEN_SMTP_PASSWORD}"`,
а сам пароль положить в переменную окружения: Пуск → «Изменение переменных среды для вашей учётной
записи» → Создать → имя `DOMWARDEN_SMTP_PASSWORD`, значение — пароль. Так же можно поступить с токеном
Telegram.

### Вебхук

```toml
[[notify.webhook]]
url = "https://hooks.slack.com/services/..."
```

Ссылки Slack и Discord программа узнаёт сама и отправляет готовое сообщение. На остальные адреса
приходит JSON с полным отчётом ([формат](docs/checks.md#json-report)). Блоков `[[notify.webhook]]`
может быть несколько.

### Когда присылать

```toml
[notify]
on = "warning"   # "warning" — при любой проблеме, "critical" — только при серьёзной,
                 # "always" — после каждой проверки, "never" — не присылать
```

## Проверка каждый день автоматически

Пусть Windows сама запускает проверку, например каждый день в 9 утра. Откройте терминал и
выполните одну команду (путь замените на тот, куда вы распаковали программу):

```powershell
schtasks /create /tn "Domwarden" /sc daily /st 09:00 /tr "\"C:\Tools\domwarden\domwarden.exe\" check --quiet"
```

Готово: если найдутся проблемы, придёт оповещение. Задание видно в программе
«Планировщик заданий» (Пуск → «Планировщик заданий»), там же его можно изменить или удалить.
Удалить командой: `schtasks /delete /tn "Domwarden"`.

На Linux то же делает cron — добавьте строку через `crontab -e`:

```cron
0 9 * * * /usr/local/bin/domwarden check --quiet
```

## Полезные команды

| Команда | Что делает |
|---|---|
| `domwarden check example.ru` | проверить домен |
| `domwarden check` | проверить все домены из файла настроек |
| `domwarden check --only tls,domain` | только сертификаты и оплату домена |
| `domwarden check --skip mail` | всё, кроме почты |
| `domwarden check -q` | показать только проблемы |
| `domwarden check -f json` | отчёт в формате JSON для программ |
| `domwarden check --lang en` | отчёт на английском |
| `domwarden init` | создать файл настроек |
| `domwarden notify-test` | отправить пробное оповещение |
| `domwarden --help` | справка |

Программа завершается с кодом `0`, если всё в порядке, `1` — если есть предупреждения,
`2` — если есть критичные проблемы, `3` — если ошибка в команде или настройках. Это пригодится
тем, кто встраивает проверку в свои скрипты.

## Частые вопросы

**«DKIM-ключ не найден среди распространённых селекторов» — это ошибка?**
Не обязательно. DKIM-ключ хранится по адресу `<селектор>._domainkey.<домен>`, а название селектора
у каждого почтового сервиса своё, и узнать его через DNS нельзя. Для Яндекс 360, Google Workspace,
Microsoft 365, VK WorkSpace и других известных сервисов программа подбирает селектор сама. Если у вас
другой сервис, найдите селектор в его настройках (раздел про DKIM или подпись писем) и впишите в
настройки: `dkim_selectors = ["ваш-селектор"]`.

**Пишет про «НУЦ Минцифры» — что делать?**
Такой сертификат открывается без ошибок только в Яндекс Браузере и Атоме. В Chrome, Firefox, Safari и
Edge посетители увидят предупреждение. Если сайт для всех, поставьте сертификат обычного центра
сертификации, например бесплатный Let's Encrypt. Его можно установить и вдобавок к сертификату НУЦ.

**«Сайт закрыт защитой от ботов»**
Сайт за Cloudflare, DDoS-Guard или похожей защитой показал программе проверку «вы не робот» вместо
страницы. Это не ошибка сайта. Сертификат и остальное программа всё равно проверила.

**Почему проверка .ru и .рф идёт дольше?**
Для этих зон данные о регистрации выдаёт сервер WHOIS реестра, а он отвечает за 3–10 секунд.
Остальные проверки идут параллельно, так что на общее время это почти не влияет.

**Сайт из списка «не открывается», хотя у меня он открывается.**
Программа проверяет сайт из той сети, где она запущена. Если включён VPN или сайт закрыт для
зарубежных адресов, результат будет другим. Запускайте проверку там, где находятся ваши посетители.

**Что означает каждое сообщение?**
Полный список всех проверок — в [docs/checks.md](docs/checks.md) (на английском).
